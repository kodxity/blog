Visualize all cells as nodes of a graph. Then, number each diagonal path (for straight path, delete the node it used immediately). Then, for each cell, for every diagonal path that is next to it (such that the diagonal path will consider this cell as bridge), we connect this node that represents the cell to the node that represents the path. Then at the end we have a bunch of graphs. In order for a valid path, then each path node must then be mapped to exactly one cell node. To solve this, we check each graph component.
Observation: I can't prove this but it's probably true - every component has exactly $x$ path nodes and $x+1$ cell nodes for some value $x$. Thus, for some total size $n$, there is $(n-1)/2$ path nodes and $(n-1)/2 + 1$ cell nodes. Thus, the answer for that graph component is $\binom{x+1}{x} = x+1$. Also this is on the basis that if we isolate some cell node (so we don't pick it), then there is exactly one possible configuration where every path node is matched to a cell node.
For implementation, I will just connect the two cells together for each path, instead of worrying about making any path nodes (graph will only be cell nodes connecting to each other).

If both sides cell nodes are bad, it's just 0 since we can't go through that path using an adjacent cell.
To check this actually, if there are no bad nodes in component, we multiply size to ans. If there is 1 bad node, we multiply 1 to ans. Else if 2 or more bad nodes, we multiply 0.
