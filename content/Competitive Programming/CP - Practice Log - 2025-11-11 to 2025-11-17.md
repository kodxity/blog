#### Kattis bread
[Bread Sorting – Kattis, Kattis](https://open.kattis.com/problems/bread)

Statement: Given permutations $a$ and $b$, we want to see if we can go from $a$ to $b$ using operations. An operation is: pick $3$ consecutive elements, swap $a[i+1],a[i+2]$, then swap $a[i],a[i+1]$.


The proof is a little too complicated for me to wrap my head around. 
It is mostly to do with the "if and only if" idea, where I know that the parity of inversions must satisfy parity of swaps, but I can't prove that if it satisfy the parity of swaps, it is still possible to sort based on the constraint that we take 3 consecutive at a time. Yes it is true if our transpositions (take two elements and swap them
) aren't limited by it's positions, but it is not too sure if we can do valid swapping if we must do the operation of taking 3 consecutive elements.


It is well known that the parity of the number of inversions is equal to the parity of parity how many swaps it takes to get to the identity permutation.

Now, I will attempt to give a valid prove that this is the only condition of going from one permutation to another. 
First, note that the operation is just doing two transpositions: swap $a[i+1],a[i+2]$, then swap $a[i],a[i+1]$. 
The operation essentially means for some 3 consecutive elements, we can put any element we choose to the left of it. By bubble sort ideas, we can essentially guarantee that we sort all elements except the last two elements (that is $a[1...n-2]$). Then, at the end we have to pray that the last two elements are already sorted.
Another important fact (although I can't prove) is that in order to get to some other permutation (e.g. identity) using only transpositions, we cannot do this with an even number of transpositions, then also an odd number of transpositions. In other words, the parity of the number of swaps we do must be the same across all ways to perform swaps into the final permutation. 
Also, an operation is two swaps, so the number of swaps must always be even.
With this in mind, if after we sort our first $n-2$ elements and is left with the last $2$ elements, if they are not automatically sorted, then we only need to perform 1 swap to sort it. Thus, we can correctly sort it in an odd number of swaps (since the previous operations we performed all use an even number of swaps). By previous statement, this means ALL valid sequences of swaps that sorts the array must use up an odd number of swaps. Thus, it is impossible to sort this using the operation, since all sequences of operations must use a up a even number of swaps.'
Now, we've proved that if the last 2 elements are not sorted by the end of sorting the first $n-2$ elements, then it is impossible. Now, the other case is if the last 2 elements are sorted. Then, it is obviously possible. 
Now, we've covered all cases: First sort the first $n-2$ elements, then if the last 2 elements are sorted, it is possible. Else if they're not sorted, it is impossible. 
Now, we must check this fast. Since performing this is similar to bubble sort, it is $O(n^2)$. Thus, we can't brute force perform operations.

An important idea is that the parity to sort a permutation using transpositions is the same as the parity of the number of inversions. So this is trivial since we can determine number of inversions in $O(n\log(n))$.
However, I will only prove that this is true for the operation of this problem. Here, the operation is essentially a right shift while moving the rightmost element to the left. Obviously, inversions of involving at least 1 other elements outside the 3 elements are not affected since the 3 elements we picked are consecutive (since the order didn't change, so inversions remain the same). Now, we only look at the inversions inside the 3 elements (both involved elements are inside the 3 we picked). The operation doesn't change order of $a[i+1],a[i+2]$, only $a[i]$ in comparison to the other two elements. Thus, the inversions that changes can only be $a[i],a[i+1]$ and $a[i],a[i+2]$. A quick examination shows that no matter the order of small to large among the 3 elements, this swap either $\pm 2$, or $-1+1 = 0$ the number of inversions. Thus, the number of inversions must change by an even number after an operations. Thus, the parity of the number of inversions stays the same.
Thus, we can determine the parity of inversions, and that would be the parity of transpositions, which is then our answer. 
However, be careful that in order to go from a permutation to another permutation, we check that the parity of inversions of the permutations are the same (instead of if they're both even). This is because we must make an even number of swaps to go to desired permutation from our initial permutation. Thus, if both are odd inversions, that means going from initial to final is odd-odd = even number of operations, which satisfies what we want.
Thus, all we have to check is if the parity of inversions of the initial and final permutations are the same.
